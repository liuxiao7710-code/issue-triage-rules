# Security Policy

`issue-triage-rules` reads local JSON and TOML files and does not make network calls.

## Reporting a vulnerability

Please open a private security advisory on GitHub when possible. If that is not available, contact the maintainer directly before publishing details.

Include:

- A short description of the issue.
- Steps to reproduce.
- Affected versions or commits.
- Any suggested mitigation.

## Supported versions

Security fixes target the latest released version and the main branch.
